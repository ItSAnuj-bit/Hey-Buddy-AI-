# Hey-Buddy-AI-
Buddy AI Ultimate Pro is an advanced voice-controlled desktop assistant built with Python. It can open apps, search files, play YouTube videos, control brightness, take screenshots, schedule tasks, and learn custom commands through an intelligent memory system, all through voice interaction and a modern graphical interface.
# Buddy AI Ultimate Pro

A powerful Python-based desktop voice assistant that automates everyday computer tasks through voice commands. Buddy AI Ultimate Pro combines speech recognition, system automation, browser control, and a modern graphical user interface to create a hands-free desktop experience.

## Features

### Voice Control

* Wake-word activation using **"Hey Buddy"**
* Speech-to-text command recognition
* Natural text-to-speech responses

### System Automation

* Open desktop applications
* Search and open files across drives
* Open folders using voice commands
* Display current system time

### Productivity Tools

* Take screenshots instantly
* Schedule tasks and reminders
* Google Calendar integration
* Custom command training system

### Browser Automation

* Google search through voice commands
* Automatic YouTube search and playback
* Selenium-powered web interaction

### Display Controls

* Increase screen brightness
* Decrease screen brightness
* Interactive animated listening indicator

### Smart Memory System

* Learn new commands and responses
* Store custom interactions in JSON format
* Persistent memory across sessions

### Modern GUI

* Full-screen desktop interface
* Live chat history
* Animated voice-listening effects
* Start, Stop, and Exit controls

## Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/Buddy-AI-Ultimate-Pro.git
cd Buddy-AI-Ultimate-Pro
```

### Install Dependencies

```bash
pip install SpeechRecognition
pip install pyttsx3
pip install selenium
pip install pyautogui
pip install screen-brightness-control
pip install pyaudio
```

### Additional Requirements

* Python 3.11+
* Microsoft Edge Browser
* Edge WebDriver
* Working microphone

---

## Usage

Run the program:

```bash
python main.py
```

After launching:

1. Click **Start**
2. Say **"Hey Buddy"**
3. Give a command

Example commands:

```text
Hey Buddy
Open app Chrome

Hey Buddy
Play Believer

Hey Buddy
Take screenshot

Hey Buddy
Increase brightness

Hey Buddy
Search Python tutorials
```
